# audit-promise-data

뉴탐사 데이터 페이지 「국감, 그 후」(newtamsa.org/p/audit-promise)가 읽는 자료와 공유 카드 이미지.

- `data/issues.json`, `data/meta.json` — 깊이 따라간 쟁점(작년 국감 지적 → 국회 요구 → 기관 보고 → 기관 밖 기록 → 올해 국감)
- `data/list/` — 2025년 국정감사 시정·처리요구와 기관 처리결과 전수 목록(처리결과보고서 18건에서 자동 추출)
- `og.png` — 공유 카드(1200×630)

## 주의
- 판정은 AI가 원문과 대조해 자동으로 매긴 것이다('자동 판정'). 기관에 불리한 판정 등 중요 건은 두 번째 AI가 따로 교차 확인한 뒤 싣는다.
- 기관 처리결과는 기관이 스스로 쓴 보고이며 사실인지 확인되지 않았다.
- 전수 목록은 PDF에서 두 방법으로 따로 추출해 대조했다. 인용할 때는 각 항목의 원문 PDF로 확인한다.
- 원자료: 국회 국정감사정보시스템, 국회 회의록·영상회의록, 피감기관 누리집, 열린국회정보, 공공데이터포털.
